## Expedition002

This folder bundles the current Expedition inputs from the repo into a single, consistently named set of files.

### Files

- `Polar.txt`: Expedition polar table (`!Expedition polar`) copied from `Builder Polar ZX.txt`
- `Heel.txt`: heel table copied from `Builder Heel ZX.txt`
- `Sailchart.csv`: sail selection chart copied from `Sailchart North.csv`
- `CrossoverSail.xml`: crossover chart copied from `CrossoverSail.xml`
- `Polar_reference_0823.txt`: older/reference polar copied from `ZX porlar latest 0823.txt`
- `Sailchart_reference_1227.txt`: older/reference sailchart copied from `ZX Sailchart 1227.txt`

### Using in Expedition

In Expedition, import/load each file from its respective module (Polar, Sail Chart, Crossover Chart).
