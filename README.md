The Polar Table, which is calculated logically, is different from the actual values, so our goal is to generate a Polar Table based on actual measurements.
The Polar to use as a base is either one generated by the ORC Sailor Service or one generated from the values published by Pogo Structure.
We measure performance using Expedition in areas and at times when the effect of the current is small, and gradually add actual measurements to the log and update it.

## Expeditionログ解析（TWA補正テーブル作成）Webアプリ

### 起動方法

```bash
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

ブラウザで `http://localhost:8000` を開き、Expeditionログ（CSV/TSV等）をアップロードしてください。

### 現在の解析（MVP）

- **入力**: Expeditionログ（列名は自由、画面でTWA列を選択）
- **補足**: TWAが 0..180 のように符号なしの場合は、任意で **AWA列** を指定するとその符号（Port/Starboard）でTWAに±を付けます。
- **推定**: 左右（Port/Starboard）の対称性から、TWAの**加法バイアス** \(b(|TWA|)\) を推定
  - 各 \(|TWA|\) ビンで、`median(starboard)` と `median(port)` から \(b \approx (m_{stb}+m_{port})/2\) を計算
  - **出力の `correction_deg` は「測定TWAに足す値」**（つまり `TWA_corrected = TWA_measured + correction_deg`）
- **出力**: `twa_correction.csv`（`abs_twa_bin_deg`, `bias_deg`, `correction_deg`, `n_port`, `n_starboard`）
