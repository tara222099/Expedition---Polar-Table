The Polar Table, which is calculated logically, is different from the actual values, so our goal is to generate a Polar Table based on actual measurements.
The Polar to use as a base is either one generated by the ORC Sailor Service or one generated from the values published by Pogo Structure.
We measure performance using Expedition in areas and at times when the effect of the current is small, and gradually add actual measurements to the log and update it.

## Expedition データ解析（このリポジトリでできること）

- **ポーラーの整形/比較**: `Builder Polar ZX.txt` と `ZX porlar latest 0823.txt` を読み、同一グリッド上で差分（kn）を作成
- **ヒール表の整形**: `Builder Heel ZX.txt` をテーブル化
- **セイルチャートの整形**: `Sailchart North.csv` をテーブル化
- **CrossoverSail.xml の抽出**: セイル境界（bezierpoints）を `tws/twa` 点群としてCSV化
- **Target Speed.xlsx との突合**: TWAブロックのみ、ポーラー補間値との差を出力（AWAブロックはTWA/AWA変換が必要なため現状スキップ）

## 使い方

Python 3.12+ で以下を実行します:

```bash
pip3 install -r requirements.txt
python3 scripts/expedition_analyze.py
```

出力は `out/` に生成されます:

- `out/polar_builder_wide.csv`
- `out/polar_latest_wide.csv`
- `out/polar_latest_minus_builder.csv`
- `out/heel_wide.csv`
- `out/sailchart.csv`
- `out/crossover_points.csv`
- `out/target_speed_long.csv`
- `out/target_vs_polar.csv`
- `out/report.md`
- `out/plots/polar_diff_heatmap.png`
- `out/plots/polar_curve_tws12.png`
